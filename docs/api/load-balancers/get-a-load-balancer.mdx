<Endpoint method={"GET"} path={"/v1/load-balancers/{uid}"} />

Returns one load balancer with its settings and targets. Each target shows the VM's current status.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.

## Path parameters

<Param name={"uid"} type={"string"} required>

</Param>

## Headers

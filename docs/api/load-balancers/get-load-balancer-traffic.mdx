<Endpoint method={"GET"} path={"/v1/load-balancers/{uid}/traffic"} />

Returns HTTP traffic through the load balancer over the chosen range: requests and 5xx
errors per time bucket, totals, 4xx count, error rate, average response time from your
VMs and bytes in and out. Figures are summed across all targets. Traffic history is kept
for 8 days, so `30d` shows at most the last 8 days.

When traffic data cannot be read (not available in this environment, or the metrics
backend is temporarily down), the response is still `200` with `available: false` and a
reason in `unavailable_reason`.

## Authentication

Send your [API key](/api#authentication) as `Authorization: Bearer <token>`. The request is scoped to the workspace in `X-Workspace-Slug`.
